# 物理キャラクタのシーン相互作用を学ぶ教科書

この教科書は、ゲームエンジニアを読者として想定し、次の論文を「機械学習の初心者でも実装までたどり着ける」ように解説するものです。

> Mohamed Hassan, Yunrong Guo, Tingwu Wang, Michael Black, Sanja Fidler, Xue Bin Peng.
> **Synthesizing Physical Character-Scene Interactions.**
> arXiv:2302.00883 (2023).
> <https://arxiv.org/abs/2302.00883>

論文 PDF: <https://arxiv.org/pdf/2302.00883v1>
補助動画: <https://youtu.be/q3hyQdaElQQ>

## この教科書のゴール

- 「キャラクタが椅子に座る／物を運ぶ」といった**物理シミュレーション上のキャラクタ制御**を、強化学習と模倣学習で実現する仕組みを理解する。
- 論文の数式・図・実験を、**ゲームエンジニアが持っている知識（剛体物理・当たり判定・PD制御・キャラクタアニメーション）に翻訳して**読み解く。
- 小さいけれど**動くミニ実装**を通じて、AMP（Adversarial Motion Priors）と強化学習の核を step by step で作れるようになる。

## 対象読者

- C++ や C# でゲームエンジンを触ったことがある、あるいは Unity / Unreal を使っている。
- 剛体物理、衝突判定、アニメーションのブレンド、状態機械（ステートマシン）などに馴染みがある。
- 一方で、**強化学習・ニューラルネット・敵対的学習（GAN）は初めて**。

逆に、次の知識は**前提としません**（すべて本編で説明します）。

- 強化学習（MDP、方策勾配、PPO）
- 模倣学習、GAN、識別器
- PyTorch によるニューラルネットの実装

## 読み方

- 通読する場合は **第I部 → 第II部 → 第III部 → 付録** の順を推奨します。
- 論文の結論だけ知りたい場合は、第II部の 07〜08 と 13〜14 だけ読むのでも構いません。
- 手を動かしたい場合は第III部を、まず読むだけなら第I部と第II部を。

各章の冒頭には「この章でわかること」「前提」を、末尾には「まとめ」「演習」を置いています。演習の解答は扱いませんが、ヒントは `docs/演習問題.md` にまとめています。

## 表記の約束

- 数式中の記号は、初出時に必ず日本語で意味を書きます。
  - 例: 状態 $s_t$（時刻 $t$ にキャラクタと環境がどうなっているかの数値のまとまり）
- ベクトル・行列は数式では太字（$\mathbf{s}$）で書き、地の文では「状態ベクトル」のように呼びます。
- コードは擬似コード（`pseudo` と表示）と実装コード（Python）を区別します。
- 図は Mermaid で書くので、GitHub や対応ビューアで図として表示されます。

## この教科書で扱わないこと

- 論文の完全な再現（IsaacGym を使う大規模並列学習は、GPU が必要なため本文では動かしません）。本格版は第30章で手順として紹介します。
- 剛体物理エンジンの実装そのもの（衝突検出アルゴリズムなど）。既存シミュレータを前提とします。

## 実装コードの場所

```
src/ml_lern/mini_amp/   人型本線のミニ実装（強化学習＋AMP）
src/ml_lern/diffusion/  付録B の拡散モデル
scripts/                学習・生成のエントリポイント
```

> **注意**: 本リポジトリの実行環境（CPU・メモリ約5GiB・CUDAなし）では、論文本来の IsaacGym は動きません。第III部のコードは MuJoCo + PyTorch（CPU）で動く小規模版です。本文のコードは「読者が自分の環境で動かす」前提で書いており、本リポジトリでは実行・検証していません。
