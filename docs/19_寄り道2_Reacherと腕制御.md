# 19. 寄り道2 — Reacher と腕制御

> **この寄り道は何につながるか**
> アームの先端を目標地点へ動かす＝**腕を伸ばす**。人型が「手を箱に伸ばす」「物を支える」ための最小モデルです。
> さらに、「目標（物体）を状態に含める」という**シーン条件付けの入り口**を学びます。これは論文の中核（第08・27章）に直結します。

## この章でわかること

- 2関節アームで目標に届くタスク
- 目標（物体）を状態に入れる意味
- 「物体を状態に含める」がなぜ論文で重要か

## 前提

- 第09章（状態）、第17章

## 1. タスク

2関節のアームを動かし、指先を目標地点に近づけます。

```mermaid
flowchart LR
    Base["付け根"] --> J1["関節1"] --> Arm1["上腕"] --> J2["関節2"] --> Hand["指先/手"]
    Hand -.->|"近づける"| Target["目標地点（物体）"]
```

ゲームでいう「腕を伸ばしてスイッチを押す」に相当します。

## 2. ここが最初の「シーン条件付け」

重要なポイント: Reacher は**目標地点の位置**を観測に含みます。これを本論文流に「物体（シーン）」として扱うと、シーン条件付けの練習になります。

```python
def get_amp_obs(self, obs, goal):
    # キャラクタ状態に物体（目標）特徴を連結する
    state, obj = self._split(obs)
    return torch.cat([state, obj], dim=-1)
```

> **つながり**: この「状態＋物体」の連結が、そのまま論文の**シーン条件付き識別器**（第08章）の入力になります。第27章では、ここに椅子や箱の情報が入ります。

## 3. 報酬 — 目標に近いほど高い

$$
r = \exp(-10\, \|\mathbf{x}_{\text{hand}} - \mathbf{x}_{\text{target}}\|^2)
$$

これは論文の $r^{\text{near}}$（式(9)）と同型です。係数 10 は「正確に合わせる」ことを要求します（第12章）。

```python
def task_reward(self, obs, goal, action, next_obs):
    _, obj_next = self._split(next_obs)         # 目標への相対座標
    dist2 = obj_next.pow(2).sum(dim=-1)
    return torch.exp(-10.0 * dist2)
```

## 4. なぜ「目標を状態に入れる」のが本質なのか

第08章・第09章で学んだことを、ここで実感します。

- 目標（物体）が状態にないと、方策は「どこへ動けばいいか」を知る手がかりがありません。
- 目標を状態に入れることで、**同じ方策が任意の目標に対応**できます（目標条件付き方策）。

```mermaid
flowchart TD
    A["目標を状態に入れない"] --> B["目標が毎回違うと<br/>方策が混乱"]
    C["目標を状態に入れる"] --> D["任意の目標位置に<br/>対応できる"]
```

これは論文の「物体を状態に入れる」設計（第09章）の最小例です。

## 6. 「つながり」のまとめ

| Reacher で学ぶこと | 人型/論文での対応 |
| --- | --- |
| 腕の目標追従 | 手を伸ばす・箱を持つ |
| 目標（物体）を状態に | シーン条件付け（第08章） |
| $\exp(-k d^2)$ の近距離報酬 | $r^{\text{near}}$（式9） |
| 目標条件付き方策 | 任意の物体配置に対応 |

## 7. Reacher の限界と次へ

Reacher は腕だけ、物体も「点」です。実際の carry では:

- 腕だけでなく**全身**（歩いて近づく、体幹で支える）が必要。
- 物体は**剛体**で、押せば動く。
- 手は物体に**接触**して支える（固定されない）。

これらは次の寄り道（歩行、第20・21章）と本命（第25〜27章）で扱います。

## まとめ

- Reacher は「腕を伸ばす」の最小モデル。
- 目標（物体）を状態に含めることで、シーン条件付けの入り口を体験する。
- 近距離報酬 $\exp(-kd^2)$ は論文の $r^{\text{near}}$ と同型。
- 全身・剛体・接触はまだ扱わない。次の寄り道と本命で発展する。

## 演習

1. 目標地点を状態から除いたら、方策はどう振る舞うと予想されますか。
2. Reacher の報酬の係数 10 を 1 に変えると、精度はどう変わるか予想しましょう。
3. Reacher と論文の carry の違いを、状態・行動・物体の3点で整理しましょう。
